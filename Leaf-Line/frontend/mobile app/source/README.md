api : 
•	code that talks to your backend (like calling POST/ai/calculate)
•	Used to handle backend API communication (like calling Express routes).

components : 
•	This folder contains reusable UI pieces.
•	These are code you use repeatedly in many of your webpages.

pages : 
•	Holds top-level pages rendered via routing (like /home, /profile, /projects).

styles : 
•	Global styles applied to the entire app.
•	Handles layout, fonts, colors, spacing.
•	Language: CSS


firebase.js : 
•	Configuration file for Firebase (auth, database, etc.).
•	Used to connect frontend to Firebase services.
•	Language: JavaScript


App.jsx : 
•	The main component that wraps your entire React app.
•	Contains routing and overall layout.
•	Language: JSX (JavaScript + HTML)

index.js : 
•	The entry point of your React app.
•	Mounts the <App /> component into index.html.
•	Language: JavaScript
